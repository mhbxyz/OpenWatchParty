# Contributing to OpenWatchParty

Thank you for helping improve OpenWatchParty. The [full contributing guide](docs/src/content/docs/development/contributing.md) covers setup, code style, testing, and the pull request process.

1. Search [existing issues](https://github.com/mhbxyz/OpenWatchParty/issues) before reporting a bug or proposing a change. Use the issue templates for bugs, feature requests, or questions.
2. For significant changes, open an issue to discuss the approach before starting work.
3. Set up the project with `just setup` and `just up`, then make your changes on a focused branch.
4. Run `just lint` and `just test` for code changes, update relevant documentation, and describe your testing in the pull request.
5. Follow the [Code of Conduct](CODE_OF_CONDUCT.md). For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

See the [development setup guide](docs/src/content/docs/development/setup.md) if you need help getting started.
